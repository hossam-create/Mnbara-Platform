## 🎨 Design Notes

### **Tone & Voice**
- **English**: Friendly, professional, reassuring
- **Arabic**: Respectful, formal yet warm, trustworthy
- **Both**: Clear, concise, action-oriented

### **Emoji Usage**
- Consistent emoji meanings across languages
- Cultural appropriateness checked
- Accessibility considerations (alt text)

### **Localization Tips**
- Text expansion for Arabic (RTL layout)
- Date/time formatting by region
- Currency display preferences
- Cultural sensitivity in imagery

This copy ensures clear communication while building trust through transparency and user-friendly language.
