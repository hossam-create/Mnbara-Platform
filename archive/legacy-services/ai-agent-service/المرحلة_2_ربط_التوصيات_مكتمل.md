## 🔄 استراتيجية الاحتياط

إذا كانت خدمة التوصيات غير متاحة:
```typescript
try {
  // محاولة الحصول على توصيات حقيقية
  const recommendations = await recommendationClient
    .getPersonalizedRecommendations(userId, 10);
  return recommendations;
} catch (error) {
  console.error('فشل الحصول على التوصيات:', error);
  // الرجوع للبيانات الوهمية
  return [
    { id: '1', name: 'كتاب إلكتروني', price: 150 },
    { id: '2', name: 'مصباح قراءة', price: 120 }
  ];
}
```

**الفوائد:**
- الخدمة تعمل دائماً
- تدهور تدريجي
- لا توجد أخطاء للمستخدم
- سجلات للتصحيح
