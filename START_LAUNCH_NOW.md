actions/checkout@v3\n      - uses: gitleaks/gitleaks-action@v2\nEOF\n\n# Commit\ngit add .github/workflows/security-scan.yml\ngit commit -m \"chore: add security scanning\"\ngit push origin main\n```\n\n**✅ HOUR 0 COMPLETE WHEN:**\n- [ ] Gitleaks installed\n- [ ] Scan completed\n- [ ] No secrets found\n- [ ] .gitignore verified\n- [ ] Security workflow added\n- [ ] GitHub Actions
