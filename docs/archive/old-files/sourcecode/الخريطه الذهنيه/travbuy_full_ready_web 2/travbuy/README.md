# TravBuy — Demo Web + Structure

نسخة أولية جاهزة للرفع على GitHub و للنشر على Vercel.

## محتويات

- `WEB/` واجهة ويب خفيفة (RTL/عربي + إنجليزي + وضع داكن).
- `LEGAL` داخل `WEB/privacy` و`WEB/terms` (عربي/إنجليزي).
- `DATA/mock` بيانات تجريبية.
- `DEPLOY/vercel` إعداد Vercel.
- `SECURITY/` سياسة أمان.
- `API/` ملاحظات حول ربط GeoCore/PHP أو أي Backend.
- `MOBILE/` ملاحظات لنسخة Flutter لاحقًا.

## تشغيل الواجهة محليًا (بدون سيرفر)

افتح `WEB/index.html` في المتصفح.

## النشر على Vercel

- أنشئ مشروع جديد على Vercel واربطه بالريبو الخاص.
- اجعل مجلد `WEB` هو المجلد المنشور (Root Directory).
- ملف `vercel.json` مرفق.
