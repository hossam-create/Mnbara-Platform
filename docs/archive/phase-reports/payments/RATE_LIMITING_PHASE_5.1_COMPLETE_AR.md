## تكامل Redis

### استراتيجية التخزين

يستخدم **Redis Sorted Sets** لتنفيذ النافذة المنزلقة:

```
Key: rl:payment:user:123
Value: Sorted Set of timestamps
Score: Request timestamp
```

**الفوائد:**
- نافذة منزلقة دقيقة (وليست ثابتة)
- تنظيف تلقائي للإدخالات القديمة
- عمليات ذرية
- موزعة عبر النسخ

### معالجة الاتصال

- **إعادة الاتصال التلقائي:** حتى 10 محاولات مع تراجع أسي
- **التدهور الرشيق:** يسمح بالطلبات عند عدم توفر Redis
- **مراقبة الاتصال:** تسجيل جميع تغييرات حالة الاتصال
- **معالجة الأخطاء:** معالجة وتسجيل شاملة للأخطاء

---

## استراتيجية توليد المفاتيح

توليد مفاتيح هرمي:

1. **المستخدمون المصادق عليهم:** `rl:{tier}:user:{userId}`
2. **مستخدمو مفتاح API:** `rl:{tier}:apikey:{apiKey}`
3. **المستخدمون المجهولون:** `rl:{tier}:ip:{ipAddress}`

## أمثلة الاستخدام

### التطبيق على المسارات

```typescript
import {
  generalRateLimiter,
  paymentRateLimiter,
  disputeRateLimiter,
  payoutRateLimiter
} from './middleware/advancedRateLimiter';

// تطبيق على جميع مسارات API
app.use('/api', generalRateLimiter);

// تطبيق محددات محددة
app.use('/api/payments', paymentRateLimiter);
app.use('/api/disputes', disputeRateLimiter);
app.use('/api/payouts', payoutRateLimiter);
```

### محدد معدل مخصص

```typescript
const customLimiter = createRateLimiter({
  windowMs: 60000,      // دقيقة واحدة
  maxRequests: 10,      // 10 طلبات
  keyPrefix: 'custom',
  handler: (req, res) => {
    res.status(429).json({
      error: 'رسالة مخصصة'
    });
  }
});

app.get('/api/custom', customLimiter, handler);
```
