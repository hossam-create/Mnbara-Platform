# Scripts Directory

This directory contains all utility scripts for the Mnbara Platform.

## Structure

- [`deployment/`](deployment/README.md) - Deployment and production scripts
- [`maintenance/`](maintenance/README.md) - System maintenance and health checks
- [`migration/`](migration/README.md) - Database migration scripts
- [`compilation/`](compilation/README.md) - Smart contract compilation scripts
- [`testing/`](testing/README.md) - Testing and verification scripts
- [`utility/`](utility/README.md) - General utility scripts
- [`cleanup/`](cleanup/README.md) - Cleanup and archive scripts

## Usage

Each subdirectory contains its own README with detailed usage instructions.
