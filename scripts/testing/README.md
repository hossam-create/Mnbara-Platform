# Testing Scripts

Scripts for testing and verification of the Mnbara Platform.

## Test Scripts

- `test-integration.js` - Integration tests
- `test-kyc-flow.js` - KYC flow tests
- `test-kyc-unit.js` - KYC unit tests
- `verify-kyc.js` - KYC verification script

## Usage

```bash
# Run integration tests
node test-integration.js

# Run KYC tests
node test-kyc-flow.js
node test-kyc-unit.js

# Verify KYC setup
node verify-kyc.js
```
