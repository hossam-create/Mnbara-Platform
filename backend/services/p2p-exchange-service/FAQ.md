**Last Updated**: 2026-01-28

## General Questions

### What is P2P Exchange?

P2P (Peer-to-Peer) Exchange is a marketplace where users can exchange currencies directly with each other without intermediaries. You can buy or sell currencies at competitive rates with other users.

### How does it work?

1. **Create Request**: Post a buy or sell request
2. **Get Matched**: System matches you with compatible requests
3. **Exchange**: Complete the exchange securely
4. **Done**: Receive your currency

### Is it safe?

Yes! We have a seven-layer security system:
1. Security deposits (5%)
2. Trust level system
3. Proof of payment requirement
4. Timeout protections
5. Communication monitoring
6. Identity verification
7. Dispute resolution

### How much does it cost?

- **Platform Fee**: 1% of transaction value
- **Protection Fee**: 0.5% for buyer protection
- **Total**: 1.5% of transaction value

### How long does an exchange take?

- **Matching**: Usually within 1 hour
- **Payment**: 30 minutes to initiate, 60 minutes to complete
- **Confirmation**: 30 minutes
- **Total**: Typically 1-3 hours

## Account & Security

### Do I need to verify my account?

Yes, you need to verify:
- Email address (required)
- Phone number (required)
- Identity documents (for transactions >$5,000)

### What is a security deposit?

A security deposit is a refundable amount (minimum $50) that:
- Protects other users from fraud
- Shows your commitment
- Unlocks higher transaction limits
- Is returned when you stop trading

### How do I add to my security deposit?

1. Go to **Profile** → **Security Deposit**
2. Click **Add Funds**
3. Enter amount
4. Choose payment method
5. Complete payment

### Can I withdraw my security deposit?

Yes, but only the available (unfrozen) amount. You cannot withdraw:
- Frozen amounts (during active exchanges)
- Amounts held for disputes
- Minimum balance requirement

### What are trust levels?

Trust levels determine your transaction limits:
- **BRONZE**: Up to $1,000 (new users)
- **SILVER**: Up to $5,000 (10 completed, 95% success)
- **GOLD**: Up to $10,000 (50 completed, 98% success)
- **PLATINUM**: Unlimited (100 completed, 99% success)

### How do I upgrade my trust level?

1. Complete exchanges successfully
2. Maintain high success rate
3. Avoid disputes
4. Complete exchanges quickly
5. Receive good ratings

## Creating Requests

### How do I create a buy request?

1. Click **Exchange** → **Create Request**
2. Select **BUY**
3. Choose currencies (I want / I have)
4. Enter amount
5. Set rate (market or custom)
6. Set expiration
7. Review and submit

### How do I create a sell request?

1. Click **Exchange** → **Create Request**
2. Select **SELL**
3. Choose currencies (I have / I want)
4. Enter amount
5. Set rate (market or custom)
6. Set expiration
7. Review and submit

### What is the best exchange rate to use?

- **Market Rate**: Current market rate (recommended for fast matching)
- **Custom Rate**: Your preferred rate (may take longer to match)

### How long should I set expiration?

- **1 hour**: For urgent exchanges
- **24 hours**: For normal exchanges (recommended)
- **7 days**: For patient exchanges or unusual amounts

### Can I edit my request after creating it?

No, you cannot edit a request. You must:
1. Cancel the existing request
2. Create a new request with updated details

### Can I cancel my request?

Yes, you can cancel:
- **Before matching**: No penalty
- **After matching**: May affect trust level
- **After payment**: Cannot cancel, must complete or dispute

## Matching

### How does automatic matching work?

The system runs every 30 seconds and:
1. Finds requests with opposite types (BUY ↔ SELL)
2. Matches currencies (A→B with B→A)
3. Checks amount compatibility (within 10%)
4. Checks rate compatibility (within 5%)
5. Calculates match score
6. Creates match if score >70

### How does manual matching work?

1. Browse the marketplace
2. Find a request you like
3. Click **Accept Request**
4. Match is created instantly

### What is a match score?

A match score (0-100) indicates compatibility:
- **90-100**: Excellent match
- **80-89**: Good match
- **70-79**: Fair match
- **<70**: No match created

Score is based on:
- Rate difference (40%)
- Amount difference (30%)
- Trust level (20%)
- Time in marketplace (10%)

### Can I reject a match?

- **Before payment**: Yes, but may affect trust level
- **After payment**: No, must complete or dispute

### Why didn't I get matched?

Possible reasons:
- No compatible requests available
- Your rate is too far from market
- Your amount is unusual
- Your trust level is too low
- Your security deposit is insufficient

## Payment & Proof

### What payment methods are accepted?

- Bank transfer
- Mobile money
- Cryptocurrency
- PayPal
- Wise
- Other methods (as agreed with counterparty)

### How do I send payment?

1. Wait for seller's payment details
2. Send exact amount using your payment method
3. Keep proof of payment (screenshot/receipt)
4. Upload proof to the platform

### What is proof of payment?

Proof of payment is evidence that you sent payment:
- Bank transfer confirmation
- Mobile money receipt
- Crypto transaction hash
- Payment screenshot
- PDF receipt

### What makes a good proof?

A good proof is:
- Clear and readable
- Shows full transaction details
- Shows correct amount
- Shows correct recipient
- Shows date and time
- Not edited or fake

### What if I can't upload proof?

1. Check file size (max 10MB)
2. Check file format (JPEG, PNG, PDF)
3. Try compressing the image
4. Try a different browser
5. Contact support

### What if seller doesn't confirm receipt?

- Wait for timeout (30 minutes)
- Dispute is created automatically
- Admin reviews within 24-48 hours
- Decision is final

## Disputes

### What is a dispute?

A dispute is when there's a disagreement about a transaction:
- Payment not received
- Wrong amount
- Timeout
- Fraud suspicion

### How are disputes resolved?

1. Dispute is created (automatic or manual)
2. Admin reviews evidence
3. Admin makes decision
4. Decision is implemented
5. Users are notified

### How long does dispute resolution take?

- **Simple cases**: 24 hours
- **Complex cases**: 48-72 hours
- **Very complex**: Up to 7 days

### What evidence should I provide?

**Buyers**:
- Proof of payment
- Bank statement
- Transaction reference
- Communication logs

**Sellers**:
- Account statement showing no receipt
- Communication logs
- Previous transaction history

### Can I appeal a dispute decision?

Yes, you can appeal within 7 days if:
- New evidence is available
- Decision was clearly wrong
- Technical error occurred

### What happens if I lose a dispute?

- Security deposit is deducted
- Trust level may be downgraded
- Transaction is reversed
- Negative rating may be applied

No hidden fees! You only pay:

Limits depend on your trust level:

### Is there a minimum transaction amount?

Yes, minimum is $10 per transaction.

### How many exchanges can I do per day?

No daily limit, but:
- Must have sufficient security deposit
- Must stay within trust level limits
- Must complete existing exchanges first

## Settlement

### What is internal settlement?

Internal settlement is when both users have platform wallets:
- Instant transfer
- No external fees
- Fastest method
- Most secure

### What is external settlement?

External settlement uses external providers:
- Blockchain-based escrow
- Supports crypto (BTC, ETH, USDT)
- Slightly higher fees
- Decentralized security

### Which settlement method is better?

- **Internal**: Faster, cheaper, easier (recommended)
- **External**: More decentralized, supports crypto

### How long does settlement take?

- **Internal**: Instant
- **External**: 10-60 minutes (depends on blockchain)

### What if settlement fails?

- System retries automatically (up to 3 times)
- Admin is notified
- Manual intervention if needed
- You are kept informed
