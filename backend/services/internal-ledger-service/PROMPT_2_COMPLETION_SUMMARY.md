## 🔄 سير العمل

### مسار النجاح
```
1. المستخدم يطلب سحب $250
   → الحالة: PENDING
   → قفل الأموال: available -$250, locked +$250

2. الأدمن يوافق
   → الحالة: APPROVED
   → الأموال تبقى مقفلة

3. الأدمن يبدأ التحويل البنكي
   → الحالة: PROCESSING
   → الأموال تبقى مقفلة

4. تأكيد التحويل البنكي
   → الحالة: COMPLETED
   → خصم الأموال: locked -$250
```

### مسار الرفض
```
1. المستخدم يطلب سحب $250
   → الحالة: PENDING
   → قفل الأموال: available -$250, locked +$250

2. الأدمن يرفض
   → الحالة: REJECTED
   → إلغاء القفل: available +$250, locked -$250
```
