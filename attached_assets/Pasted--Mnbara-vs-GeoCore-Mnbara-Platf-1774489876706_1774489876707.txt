## 🔍 الفحص المطلوب لـ GeoCore

### الخطوات:

```bash
1. Clone المشروع:
   git clone https://github.com/hossam-create/geocore-next
   cd geocore-next

2. افحص الملفات:
   □ cat PRD.md
   □ cat TASKS.md
   □ cat CLAUDE.md
   
3. افحص Backend:
   cd backend
   ls -la cmd/api
   ls -la internal/
   
4. افحص Frontend:
   cd ../frontend
   ls -la src/app
   ls -la src/components

5. جرب التشغيل:
   cd ..
   make dev
   # أو
   docker-compose up

6. اختبار:
   □ Frontend يفتح؟
   □ Backend API يرد؟
   □ Database connected?
```

### الأسئلة المهمة:

```yaml
محتاج إجابات على:
  1. هل الكود فعلاً موجود في backend/internal/?
  2. هل الـ frontend/src فيها components حقيقية؟
  3. هل docker-compose يشتغل أول مرة؟
  4. هل الـ WebSocket implementation موجودة؟
  5. هل الـ authentication شغال؟
```
