## 🏗️ Architecture Overview

### Microservices:
1. **Listing Service** (Port 3001) - Product catalog
2. **Cart Service** (Port 3002) - Shopping cart
3. **Payment Service** (Port 3003) - Stripe integration
4. **Crowdship Service** (Port 3004) - Delivery matching
5. **Compliance Service** (Port 3005) - KYC/AML
6. **Seller Service** (Port 3006) - Seller management

### Infrastructure:
- **Kubernetes**: 5-node cluster
- **PostgreSQL**: Primary + Replica
- **Redis**: Cluster mode
- **Elasticsearch**: 3-node cluster
- **CDN**: CloudFlare
- **Monitoring**: Prometheus + Grafana
