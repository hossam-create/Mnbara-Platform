## 🔄 **Recovery Process**

If any archived files need to be restored:

1. **Navigate to archive folder**:
   ```bash
   cd archive/
   ```

2. **Identify needed files**:
   ```bash
   ls -la | grep "filename"
   ```

3. **Restore files**:
   ```bash
   mv archive/filename.ext src/path/to/filename.ext
   ```

4. **Commit restoration**:
   ```bash
   git add .
   git commit -m "Restore: filename.ext from archive"
   ```
