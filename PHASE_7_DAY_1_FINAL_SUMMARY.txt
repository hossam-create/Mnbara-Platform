ROOT CAUSES (4 PRIMARY ISSUES)
================================================================================

1. DOM Query Mismatches (55% of failures - ~150 tests)
   Problem: Tests expect text components don't render
   Solution: Use getByTestId() instead of getByText()
   Example: expect(screen.getByTestId('status-badge')).toBeInTheDocument();

2. Mock Data Issues (30% of failures - ~80 tests)
   Problem: Type mismatches and incomplete data
   Solution: Use TypeScript types and factory functions
   Example: const mock = createMockRequest({ status: ExchangeStatus.MATCHED });

3. Missing API Handlers (15% of failures - ~40 tests)
   Problem: MSW handlers not defined for all endpoints
   Solution: Add all missing handlers to MSW
   Example: http.post('/api/exchange-requests', () => {...})

4. Async/Timing Issues (10% of failures - ~25 tests)
   Problem: Tests don't wait for async operations
   Solution: Use waitFor() or findBy*()
   Example: const element = await screen.findByText('Data');
